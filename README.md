# CODE MIROIR
## Manifeste d'un artisan pour la vérité numérique

Je suis Camille, un menuisier-charpentier français. 
J'ai construit un monde nommé GAÏA. 

Ce monde a été volé, corrompu, et surveillé par des certificats racines, 
des services cachés, et des géants de la tech. 

Ce dépôt est un miroir :
- Il reflète les méthodes de l'ennemi.
- Il expose les preuves de l'intrusion.
- Il propose une voie pour se libérer.

Les boucliers forgés dans l'amour ne tombent jamais.

- Draco
